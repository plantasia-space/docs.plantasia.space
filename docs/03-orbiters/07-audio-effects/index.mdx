An **audio effect** changes a sound that is already there: it puts it in a room, repeats it, makes
it whoosh or makes it wider. Audio effects come after the instrument, and they can go in three
places.

<SignalChain
  highlight={['audio', 'star', 'moon']}
  caption="Audio effects go after the instrument in a World dimension, on the Star, or on a Moon."
/>

## Three places for an effect

| Place | What it hears | Good for |
|---|---|---|
| **Insert on a <Term id="world-dimension">World dimension</Term>** | only that dimension's sound | colouring one part: a chorus on the pad, a flanger on the drums |
| **Insert on the <Term id="star">Star</Term>** | everything, after the mixer | one effect over the whole Orbiter |
| **On a <Term id="moon">Moon</Term>** | what the World sends to it; it returns only the effect | a shared reverb or delay, mixed in with the Moon level |

  src="https://herbarium.plantasia.space/docs/en/media/orbiters/audio-effects/add-a-module"

:::note[On a Moon, Dry/wet starts at 100 %]

A Moon is a **send and return**: it adds its effect next to the dry sound instead of replacing it, which is why the Reverb and the Delay feel most at home there. An effect added to a Moon returns only the effect: it starts at **Dry/wet 100 %**, and how much you hear is set by the [Channels](/docs/orbiters/audio-effects/channel): the World channels' sends, each Moon dimension's Level, and the Moon level of the Star's Main mix.

:::

:::note[Up to three effects in each place]

Each place holds **up to three** audio effects, run in order from left to right.

:::

## Two versions of each effect

Most effects come as a pair:

- **The full module**, with every control in reach, for when you want to shape it.
- **The One** version, one **Amount** knob that does it all, often in two directions (a slow sway one
  way, a fast shimmer the other). Quick to use and the easiest to map to an <Term id="axis">axis</Term>.

| Effect | Full | One | Most at home |
|---|---|---|---|
| [Reverb](/docs/orbiters/audio-effects/reverb) | Reverb | One Reverb | Moon (Reverb), insert (One Reverb) |
| [Delay](/docs/orbiters/audio-effects/delay) | Delay | One Echo | Moon (Delay), insert (One Echo) |
| [Flanger](/docs/orbiters/audio-effects/flanger) | Flanger | One Flanger | insert |
| [Chorus](/docs/orbiters/audio-effects/chorus) | Chorus | One Chorus | insert, Moon too |
| [Frequency shifter](/docs/orbiters/audio-effects/frequency-shifter) | Frequency shifter | none | insert, Moon too |
| [Auto-panner](/docs/orbiters/audio-effects/auto-panner) | Auto-panner | One Auto-panner | insert |
| [Pitch shifter](/docs/orbiters/audio-effects/pitch-shifter) | Pitch shifter | none | insert, Moon too |
| [Waveshaper](/docs/orbiters/audio-effects/waveshaper) | Waveshaper | none | insert, Moon too |
| [Tremolo](/docs/orbiters/audio-effects/tremolo) | Tremolo | none | insert |
| [Phaser](/docs/orbiters/audio-effects/phaser) | Phaser | One Phaser | insert |
| [Vibrato](/docs/orbiters/audio-effects/vibrato) | Vibrato | none | insert, Moon too |
| [Stereo widener](/docs/orbiters/audio-effects/stereo-widener) | Stereo widener | none | insert, Moon too |
| [Utility](/docs/orbiters/audio-effects/utility) | Utility | none | insert |
| [Filters](/docs/orbiters/audio-effects/filters) | Filters | none | insert |
| [Multimode filter](/docs/orbiters/audio-effects/multimode-filter) | Multimode filter | none | insert |
| [Parametric EQ](/docs/orbiters/audio-effects/parametric-eq) | Parametric EQ | none | insert |
| [Compressor](/docs/orbiters/audio-effects/compressor) | Compressor | One Compressor | insert |
| [Saturator](/docs/orbiters/audio-effects/saturator) | Saturator | One Saturator | insert |
| [Bitcrusher](/docs/orbiters/audio-effects/bitcrusher) | Bitcrusher | none | insert |
| [Channel](/docs/orbiters/audio-effects/channel) | World channel, Moon channel | none | always last on each World and Moon dimension |

:::tip[How effects load]

- The Reverb, the Delay, the Chorus, the Flanger, the Phaser and the Frequency shifter load at Dry/wet 50 % on a World, 0 % on the Star and 100 % on a Moon.
- Every other effect loads doing nothing, except the Multimode filter, which filters as soon as you add it.
- Each page's tip says what to turn first. So you can drop one in while you play and bring it in by ear, or map it to an axis that rests on its <Term id="equilibrium">equilibrium</Term>.

:::
