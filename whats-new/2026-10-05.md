- **Reverb and One Reverb.** A room-to-hall reverb with every control in reach, and a one-knob version that goes from a close room to a long hall one way and a bright plate the other. [Read the docs →](/docs/orbiters/audio-effects/reverb)
- **Delay and One Echo.** A stereo delay synced to the tempo, with ping-pong and freeze, and a one-knob echo: a dub echo turned up, a slapback turned down. [Read the docs →](/docs/orbiters/audio-effects/delay)
- **Flanger and One Flanger.** A stereo flanger that sweeps in time across a room, and a one-knob version with a slow jet one way and a hollow sweep the other. [Read the docs →](/docs/orbiters/audio-effects/flanger)
- **Chorus and One Chorus.** Make a sound wider and thicker without making it louder: every control in reach, or one knob with a slow sway one way and a fast shimmer the other. [Read the docs →](/docs/orbiters/audio-effects/chorus)
- **Note Echo.** Every note you play comes back after a delay, up to 15 times, each repeat with its own level and pitch. [Read the docs →](/docs/orbiters/midi-effects/note-echo)
- **Velocity.** Reshape how hard each note plays: drive it, compress it, randomise it, or set it to one fixed level. [Read the docs →](/docs/orbiters/midi-effects/velocity)
- **Track player screen.** The Track player now shows what Speed does to the sound: a plant that runs at Speed, its height the pitch you hear. [Read the docs →](/docs/orbiters/instruments/track-player)
